# اجرای مهاجرت دیتابیس

بعد از ساخت دیتابیس PostgreSQL و تنظیم `DATABASE_URL`، فایل `001_initial.sql` را با ابزار `psql` اجرا کن:

```bash
psql "$DATABASE_URL" -f migrations/001_initial.sql
```

در PowerShell می‌توانی به‌جای متغیر شِل از رشته اتصال خودت استفاده کنی، اما آن را در فایل‌های پروژه یا اسکرین‌شات عمومی قرار نده. این مهاجرت جدول پروژه‌ها و پیام‌های تماس را می‌سازد و سه پروژه اولیه را وارد می‌کند.
